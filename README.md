# Sairoop NK | AI & Full Stack Developer - Portfolio

This is the repository for my professional portfolio website, showcasing AI, Full Stack, and Software Development projects.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Framer Motion

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure
- `src/app/` - Next.js App Router (pages and layouts)
- `src/components/` - React components (UI primitives, layouts, sections)
- `src/data/` - Static data for the portfolio (projects, experience, skills)
- `src/lib/` - Utilities and integrations
- `src/types/` - TypeScript type definitions
